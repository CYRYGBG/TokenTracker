# TokenTracker 个人同步版 — 需求规格（REQUIREMENTS）

> 本文档是 fork 的需求权威。每次任务开始先读本文件、`UPSTREAM.md`、`STATUS.md`。
> 标注说明：【已确认】= 用户明确确认；【默认】= 实现采用的默认决策（可被用户推翻）；【待核实】= 需查代码/官方资料或问用户的事实。

## 0. 产品定位

【已确认】个人使用的 AI 编程用量统计与多设备分析工具。**无官方 TokenTracker 账号**，通过用户自己的 WebDAV 网盘（首个目标：坚果云）同步多设备统计明细。主要入口是 macOS 状态栏面板；保留 Windows 托盘与完整统计窗口。目标平台：macOS + Windows（Linux 非首版验收目标，不为此大改上游跨平台结构）。

【已确认】核心原则：**沿用上游成熟的采集、增量扫描、计数、去重、成本计算、项目与会话分析**。本 fork 的主要变化是：多端 WebDAV 同步、必要的数据持久化、产品界面精简。**不是重写统计引擎。**

用户当前主要使用：Codex、ZCode、DeepSeek Harness；但必须保留上游全部工具（权威清单以 rollout.js 采集器为准）的采集能力与扩展能力，不得裁剪为只支持这三个。

## 1. 保留范围

【已确认】以下能力全部保留（不重构、不裁剪）：

- 上游所有 AI 工具采集：增量扫描、日志格式兼容、压缩记录（zstd 等）、上游去重与数据修复机制。
- Token 明细口径沿用上游归一化（`input_tokens` 不含缓存读写；reasoning 对 Codex/acode/every-code/OmO/Cline/Muse 是 output 子集不重复计费；成本绝不用 `total_tokens` 计算——见 AGENTS.md「Token normalization」）。
- 总览、时间范围筛选、趋势、热力图、模型/工具分布、费用分析、设备维度、项目维度、会话明细。
- 会话分析中已有实际依据的字段（上下文、子代理、性能、用量完整性）；某工具缺数据时如实显示"不支持/不可用"，不编造。
- 有实际厂商接口支撑的额度、重置时间与提醒。**厂商账号额度是账号级数据，多台电脑同账号不得相加。**
- macOS 状态栏 + 面板、Windows 托盘 + 统计窗口、完整统计窗口（Dashboard/Sessions/Limits 页面体系）。
- 手动导入导出、备份恢复、主题、语言、货币、开机启动、网络代理、本地诊断。
- 上游 `wrapped` 年度回顾等**纯本地统计**展示功能【默认：保留，因其为统计能力而非装饰】。

## 2. 删除范围（首版退出运行路径）

【已确认】以下官方云/商业化/装饰功能从**路由、导航、启动钩子、后台任务、原生菜单、深链、构建依赖、默认网络请求**中真正移除，不能只隐藏按钮：

| 领域 | 涉及（详见 UPSTREAM.md 改动地图） |
|---|---|
| 官方注册/登录/OAuth/找回密码/账号绑定/设备授权/凭证续期 | LoginPage、ResetPasswordPage、NativeAuthCallbackPage、device-login、cloud-account 等 |
| 官方排行榜/公开主页/点赞/社区 | LeaderboardPage、LeaderboardProfilePage |
| 官方付费云同步/会员/试用/兑换码/支付/账单 | CloudPage、CloudCheckoutPage、billing 相关 |
| Skills 管理器 | SkillsPage、SkillDetailPanel、skills-manager |
| 宠物/皮肤/成就徽章/灵动岛 | PetPage、pet-packages、AchievementsPage、DynamicIsland |
| 独立桌面小组件（首版不纳入；状态栏/托盘**不是**小组件） | WidgetKit target 构建排除 |
| 官方心跳/遥测/非必要上报 | telemetry、sentry 默认关闭、PostHog |
| 自部署向导/营销入口/IP 检测/服务状态页/质量每美元实验 | SelfHostPage、IpCheckPage、ServiceStatusPage、LandingPage 营销内容 |

【已确认】仍保留本地 API 的接口安全校验（`~/.tokentracker` 本地 serve 的防护逻辑不动）；"无官方账号"≠"本地接口无防护"。

【默认】删除采用"按依赖清理"：成品入口和运行路径真正去掉；历史 SQL、平台文件、素材、辅助脚本不要求一次性清空，但不得在构建或运行时意外启用。

## 3. 项目 / 会话 / 历史统计语义

【已确认】关键语义（实现细节见 SYNC_DESIGN.md）：

1. 不同步 AI 工具的原始工作对话目录；WebDAV 只同步**统计明细**。
2. Mac ↔ Windows 互看对方的项目与会话统计。只有 Token 汇总的版本是中间里程碑，不是完成。
3. 同步字段白名单：设备、项目标识/名称、会话标识/标题、来源工具、模型、时间、Token、估算费用、有依据的分析指标。**绝不同步**：对话正文、回复、代码、文件内容、工具调用参数、API Key、cookie、登录 token、带凭证的 Git URL。绝对路径与本地恢复命令默认留在源机器。
4. 相同 Git 仓库可辅助识别为同一项目（统一 SSH/HTTPS 时清除凭证）；**不同项目不得仅因同名合并**；无 Git/不确定匹配的保留独立身份；支持手动合并/拆分且保留来源可恢复。
5. 会话与设备用稳定身份：重传、重启、恢复归档、重扫不得重复累计；身份冲突不得静默覆盖。
6. 已归档会话继续计入用量与费用；扫描实际可读的归档记录。
7. 在源 AI 工具中删除会话，**不抹掉**已采集的统计明细；"找不到源记录"标记为"源记录不可用/本次未更新"，不自动删除历史。
8. 会话明细长期持久化，不得完全依赖重扫原始文件重建的临时缓存。
9. 隐藏只影响默认列表展示，不扣减总用量/费用/项目汇总；有"显示已隐藏项"与取消隐藏；隐藏状态跨设备一致；不向源工具发删除指令。
10. 允许修正已确认的错误数据；一次不完整扫描不得当作归零；全量重扫不得丢失源日志已清理的历史；破坏性迁移前有可恢复备份。

## 4. WebDAV 同步需求

【已确认】：

- 首个验证目标坚果云，协议保持通用（标准 WebDAV），不绑定坚果云专有扩展。
- 设置项：服务地址、用户名、应用密码、同步目录、设备名称、连接测试、启用开关、立即同步、上次成功时间、失败原因、设备数据更新时间。
- **不做应用层文件内容加密**（用户明确决定，不再反复追问）；仍强制 HTTPS 传输；应用密码存平台安全凭证存储（macOS Keychain / Windows DPAPI 或凭据管理器），不写入仓库/日志/可同步配置。
- 同步跑在本地后台 serve 进程内；关窗留在状态栏时继续工作；启动、唤醒、联网恢复后补同步。
- 有变化才传输 + 节流；默认分钟级检查周期（理由记录在 SYNC_DESIGN.md）。
- 离线/超时/认证失效/限流/服务端异常时本地采集与查看不受影响；重试带退避；成功前不丢待同步数据。
- 每设备只写自己的数据文件，其他设备读取合并；导入数据不得再次当作本机新用量导出。
- 版本化数据格式、单调修订号/代际、明确快照/增量语义、校验和、幂等导入、恢复点；不按本机时钟判新旧；处理设备重装、序号回退、旧备份恢复、客户端版本差异。
- 考虑断网中途、半文件、清单与内容不一致、并发写、旧快照晚到；按服务端能力探测 ETag/If-Match/条件写，不假设可选行为被所有 WebDAV 支持。
- 账号级数据（Cursor、TRAE CN 等）沿用上游去重语义，多机读同一账号不得翻倍。
- 状态栏/托盘/完整界面统计范围一致，可区分本机/全部/指定设备；异步失败不得把多机总量悄悄换成本机数字。
- 同步与备份分开：远端保留有界历史版本，不因本地清理或设备离线删除远端历史；首版不做自动传播的破坏性删除。

【待核实→设计】上游 `local-usage-transfer.js` 快照模块是否可复用为导出载体（字段覆盖、体积、设备数限制）——结论见 SYNC_DESIGN.md。

## 5. 价格与实际支出

【已确认】用户实际用法：Codex 订阅套餐；ZCode 订阅套餐 + 部分厂商 API；DeepSeek Harness 主要走 DeepSeek 官方 API。需要**同时**看"按模型单价估算的消耗"与"真实支出"两个口径，不合并、不相加。

- 保留上游价格体系与匹配顺序（curated-overrides > LiteLLM 缓存/在线 > seed 兜底；订阅来源 $0；DeepSeek 分时；长上下文档；速度档）。
- 新增：价格来源显示、最后获取时间、当前使用的价格版本、手动刷新（**必须真正刷新常驻 serve 进程内存表**——上游 `ensurePricingLoaded` 只在进程启动加载一次，这是已知缺口）、自定义价格入口。
- 自定义价格按厂商/来源+模型粒度生效；用户自定义规则可随同步分发，凭证不同步。
- 历史费用重算规则明确：默认以采集时价格依据为准；明确触发的重估允许；后台不得静默改已确认账单；无价格证据的旧数据标"估算"。
- 实际支出：首版提供手动费用记录（充值/订阅付款，含金额、日期、周期）；充值 ≠ 消费；同一笔付款多台机器不重复计；不把套餐费当作每请求边际成本。自动账单接入仅在查证官方接口与凭证可得后再做，做不到就标"未核对"，不阻塞其他开发。
- 无定价与确认免费要区分；各工具的额度/会话/性能支持程度透明。

## 6. 验收标准（摘要，完整清单见用户原始需求第 9 节）

- 采集/定价核心回归通过（重点 Codex、ZCode、DeepSeek Harness，不破坏其他工具）。
- 两份隔离设备数据双向同步后一致；重传/连续采集/重启不重复累计。
- 同项目不同路径归并、不同项目同名不合并、手动拆分可恢复。
- 会话统计覆盖更新不叠加；向下修正规则明确。
- 归档、源删除、暂时不可读、隐藏/取消隐藏行为符合第 3 节语义。
- 各类同步故障可解释可恢复；运行路径无官方登录/云/排行榜/遥测请求；允许的联网功能正常。
- 网盘文件与日志不含凭证/正文/代码/带认证路径。
- 价格手动刷新对常驻服务生效；估值与真实支出不混淆。
- 界面/状态栏/托盘统计范围一致；前端、后端、原生构建检查通过。

## 7. 环境事实

- 无坚果云应用密码期间：完成本地 WebDAV 实现、故障注入测试、隔离双设备集成测试；**不得把模拟服务验证说成坚果云实测**。
- 当前开发机仅 macOS（darwin arm64，Node 25）；Windows 仅能做构建级检查，不得宣称实机通过。
- 本机访问 GitHub 需代理 127.0.0.1:7897（git 与 npm 原生模块下载均需要）。
- 不发布 npm 包、不做正式 Release、不推送远端，除非用户另行授权。

## 8. 最终交付与新增界面（2026-10-27 用户补充）

【已确认】交付目标是可安装的 macOS 应用与 Windows 安装程序；开发命令或仅 EmbeddedServer 不算最终交付。新增 WebDAV、设备、价格与支出界面必须复用官方现有组件、字体、色彩、卡片、间距和深浅色主题，保持一致风格。实际未验证的系统/真实网盘行为仍需如实区分，不能把构建产物存在写成所有实机通过。

【已确认，2026-10-27】用户授权将上述两个平台安装包发布到自己的 GitHub fork，供另一台电脑下载；不是 npm 发布，也不写入原作者仓库。

## 9. 设备卡片、更新与状态栏额度（2026-10-28 接续确认）

- 首页沿用官方左列 DeviceUsageCard，接入 WebDAV/旧手动导入的设备名称、平台、所选日期用量和同步时间。点击切换全局统计范围；零用量设备仍保留，账号级用量继续按原规则去重并独立展示。
- 恢复个人版应用内检查更新与可选自动更新，只从自己的 GitHub fork 获取 personal-vX.Y.Z 稳定发布及精确平台资产，必须通过 SHA-256；macOS 还验证 bundle ID、内嵌版本及签名，完整复制后再替换旧应用。默认自动更新关闭，手动检查不受此开关限制。
- macOS 设置和右键菜单保留 Codex/Claude 五小时额度选项。缺凭据/查询失败时可预先选择，显示横线，不伪造额度；有真实数据时复用原有百分比、显示模式与重置倒计时。主动隐藏的厂商仍保持隐藏。
- 1.4.11 尚无更新入口，升级到 1.4.12 需一次手动覆盖安装，后续可从应用内更新。安装过程不删除个人统计目录。

## 10. ZCode 接续会话补充要求（2026-10-28 复核）

- 前端与官方使用相同组件、布局和主题；同步放在设置内，价格、支出和项目归并表单也复用 SettingsRow。
- 已有更新入口的本机后续升级一律走应用内更新。Windows 无入口旧版迁移所需提示词已在接续会话交付。
- 凭证字段未编辑时显示当前配置的纯文本，密码只显示是否保存；点击编辑才出现输入框，保存并测试合并，取消丢弃草稿。
- 后台同步、间隔、同步会话标题随选随存，与凭证编辑分开；不能顺带提交或覆盖未测试草稿，失败不能显示为已应用。
- 间隔支持分钟/小时；自动轮询、文件变化、重启遵守同一间隔，立即同步可绕过间隔；认证暂停及服务端退避保留。
- 同步状态用设备名称和本地分钟精度时间，不显示机器码。
- 去除页首范围选择器，沿用官方 Token 总数卡片内设备下拉；左侧设备卡片共用页面状态，概览、明细、趋势、热力图、模型、项目范围一致。
- 用户已反馈 Windows 实机安装测试且 Windows 同步记录到达 Mac，记为基础链路的用户实测证据，其余实机行为逐项保留验证边界。
